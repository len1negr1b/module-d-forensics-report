Модуль D. Цифровая криминалистика (сетевой захват трафика)

1. Краткий обзор (Executive Summary)

30 июля 2024 г. в локальном сегменте сети компании (172.16.1.0/24, домен wiresharkworkshop.online) зафиксирована компрометация клиентской рабочей станции DESKTOP-SKBR25F (172.16.1.66), принадлежащей пользователю ccollier. На станции было выполнено вредоносное Java-приложение — удалённый доступ (RAT) StrRAT версии 1.6 (идентификатор кампании оператора: 1BE8292C).

Вектор атаки: запуск на станции пользователя Java-загрузчика, который самостоятельно (TLS-клиент Java, а не браузер) скачал компоненты полезной нагрузки с GitHub (объекты релиза, ~828 КБ) и Maven Central (~8,9 МБ), после чего инициировал обратное (reverse) TCP-соединение с внешним C2-сервером 141.98.10.79:12132. Для сбора сведений о местоположении жертвы вредоносная программа обратилась к легитимному сервису ip-api.com.

Хронология (окно записи трафика): 30.07.2024 с 05:38:48 до 05:48:34 (UTC+3). Компрометация активна не позднее чем с 05:40:05; на момент окончания записи C2-канал продолжал работать (компрометация не завершилась).

Цель и результат действий злоумышленников: получение скрытого канала удалённого управления рабочей станцией и сбор сведений о жертве (имя узла и пользователя, ОС, антивирус, геолокация, заголовки активных окон — зафиксирована телеметрия наблюдения за окнами PowerPoint «pounds-formula», Paint «Fanad Head Lighthouse» и др.). Признаков шифрования файлов, вымогательства или разрушительных действий в окне наблюдения не зафиксировано; команды оператора в канал не передавались — вредоносная программа находилась в режиме поддержания связи (бикон каждые ~5 секунд).

4.2. Вектор(ы) атак и подтверждающая информация

Вектор: выполнение вредоносной Java-программы на рабочей станции (загрузчик → StrRAT).

  • Доказательство 1 (принадлежность загрузки Java-приложению): JA3/TLS-профиль клиентских соединений к github.com, objects.githubusercontent.com и repo1.maven.org — 771,49196-49195-…-255,0-10-11-13-50-23-43,23-24-25-256-257-258-259-260,0 — соответствует стеку Java (JSSE, Java 11+): характерный набор шифров, отсутствие расширений ALPN и renegotiation_info, свойственных браузерам. Браузерные загрузки исключаются.
  • Доказательство 2 (установка управления): исходящее соединение на нестандартный порт 12132 (141.98.10.79) и текстовый бикон с явной самоидентификацией «STRRAT … 1.6» — протокол известного Java-RAT StrRAT (длина сообщения в префиксе вида <len>\r\n\r\n).
  • Доказательство 3 (скрытность): подмена User-Agent при обращении к ip-api.com (устаревший Chrome 73 при фактическом Java-клиенте), использование легитимных сервисов (GitHub, Maven Central, ip-api, Oracle) для доставки и работы — обход репутационных фильтров.

Примечание: фишинговая электронная почта и входящие атаки в захвате трафика отсутствуют (SMTP-трафика нет); первичное попадание загрузчика на станцию произошло до начала записи (до 05:38:48) и по pcap не восстанавливается.

4.3. Описание последовательности атаки и подтверждающая информация

Этап 1. Подготовка (до 05:38:48)

Загрузчик (Java-приложение) уже присутствовал на станции DESKTOP-SKBR25F; момент его попадания на хост за пределами окна записи.

Этап 2. Загрузка полезной нагрузки (05:39:52–05:40:03)

Java-процесс инициирует одновременные DNS-запросы github.com и repo1.maven.org, устанавливает TLS-сессии и скачивает объект релиза GitHub (~828 КБ) и артефакты Maven Central (~8,9 МБ). Содержимое зашифровано TLS; ключи сессий в pcap отсутствуют.

Этап 3. Установка канала управления (05:40:05)

Установлено исходящее TCP-соединение к C2 141.98.10.79:12132 (порт 49754 на стороне жертвы). Протокол — открытый текст поверх TCP: клиент передаёт префикс длины <len>\r\n\r\n и сообщение.

Этап 4. Сбор сведений о системе (05:40:06–05:40:07)

GET http://ip-api.com/json/ (подменённый UA Chrome/73) → геолокация по публичному IP 136.49.34.127 (US). Формируется бикон: имя узла, имя пользователя, ОС, разрядность, антивирус, версия ВПО (1.6), страна, статус «Not Installed», таймер простоя.

Этап 5. Поддержание доступа и наблюдение (05:40:07–05:48:34)

Биконы каждые ~5 секунд (всего 62). Поле Base64 в биконе содержит заголовок активного окна: расшифрованы значения «pounds-formula [Compatibility Mode] - PowerPoint», «Fanad Head Lighthouse - Paint», «Pictures», «Documents», «Home», «Program Manager» — оператор получал телеметрию о работе пользователя. Активных команд оператора (shell, файловые операции и т.п.) в канале не зафиксировано.

Этап 6. Дополнительная активность (05:44:29)

Обращение к javadl-esd-secure.oracle.com — проверка/загрузка Java Runtime (окружение для Java-импланта). Прочий трафик сеанса — штатная активность Windows/Office (MSN, Bing, login.microsoftonline.com, autodiscover), служебный доменный трафик (Kerberos, LDAP, SMB/GPO, NBNS, NTP, LLMNR).
